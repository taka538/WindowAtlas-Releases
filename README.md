# WindowAtlas

開きすぎたウィンドウを、整理してすぐ見つける。

Windowsのウィンドウをタブやグループでまとめ、
名前で検索して切り替えられるアプリです。

## できること

- タブ・グループでウィンドウを整理
- タイトル・表示名・アプリ名で検索
- キー操作ですばやく呼び出し
- リスト／サムネイル表示
- アプリ・ファイル・フォルダーのランチャー

## ダウンロード

現在、0.1.0 ベータ版の公開準備中です。

公開後は、このページからインストーラーをダウンロードできます。

## 使い方

1. インストールして起動
2. 無変換キーを押して一覧を表示
3. ウィンドウ名をクリックして切り替え

呼び出しキーや動作は設定で変更できます。

## ご利用にあたって

- Windows x64向け。起動には管理者権限が必要です。
- ベータ版のため、一部の操作・環境は未確認です。
- 利用状況の送信は初期設定でオフです。
- 不具合や要望は、アプリ内の［フィードバック］から送れます。
